# 장기대기 선별기 (WaitSieve)

엑셀로 받은 라인 물량 표에서 오래 머문 물량을 규칙으로 골라 주는 윈도우 프로그램이에요.

이 저장소는 실행 파일을 배포하는 곳이고, 소스 코드는 들어 있지 않아요.

---

## 내려받기

### [⬇ 최신 버전 받기](../../releases/latest)

| 파일 | 설명 |
|---|---|
| `WaitSieve.exe` | 프로그램이에요. 설치 없이 두 번 클릭하면 바로 실행돼요 |
| `WaitSieve-manual.md` | 사용설명서 |
| `rules_sample.json` | 규칙 견본. 프로그램의 [규칙 불러오기]로 열어요 |

## 처음 실행할 때

1. `WaitSieve.exe` 를 바탕화면이나 내 문서처럼 쓰기 가능한 폴더에 두세요. `C:\Program Files` 는 피해 주세요.
2. "Windows의 PC 보호" 파란 창이 뜨면 **[추가 정보] → [실행]** 을 눌러요. 서명 인증서가 없는 프로그램이라 뜨는 안내예요.
3. 관리자 권한은 필요 없어요.

## 이미 쓰고 있다면

따로 받지 않아도 돼요. 프로그램을 켜면 새 버전을 알려 주고, **[설정] → 업데이트** 에서 버튼 한 번으로 바뀌어요.
규칙과 설정은 그대로 남아요.

## 할 수 있는 일

- 엑셀 파일·CSV 읽기, 엑셀에 열어 둔 문서에서 가져오기, 복사한 표 붙여넣기
- 컬럼마다 날짜·숫자·텍스트를 알아서 가려내고, 틀리면 직접 고치기
- "공정 도착 후 3일 넘게 대기" 같은 규칙을 여러 개 만들어 한 번에 골라내기
- 고른 컬럼으로 정렬하고, 라인·공정별로 묶어 건수와 수량 세기
- 결과를 엑셀 파일로 내보내기
- 로컬 LLM(Ollama 등)이나 직접 지정한 LLM 으로 말로 규칙 만들기, 결과 요약

## 데이터는 어디로 가나요

- 읽은 표는 프로그램 안에서만 다루고 따로 파일로 남기지 않아요.
- 스스로 연결하는 바깥 주소는 새 버전 확인용 github.com 하나예요. 이때 보내는 데이터는 없어요.
- LLM 을 쓸 때만 표의 일부(컬럼 이름, 예시 값, 결과 행)가 설정에 적은 주소로 가요.

## 필요한 환경

- Windows 10 이상
- 보호(DRM)가 걸린 엑셀 파일을 읽으려면 엑셀이 설치되어 있어야 해요
