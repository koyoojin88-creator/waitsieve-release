# SUMI (수미)

**Smart Unified Material Insight** — 처음부터 끝까지, 물량을 한눈에.

엑셀로 받은 라인 물량 표에서 오래 머문 물량을 규칙으로 골라 주는 윈도우 프로그램이에요.

이 저장소는 실행 파일을 배포하는 곳이고, 소스 코드는 들어 있지 않아요.

---

## 내려받기

### [⬇ 최신 버전 받기](../../releases/latest)

| 파일 | 설명 |
|---|---|
| `SUMI-Setup-버전.exe` | 설치 파일이에요. 두 번 클릭하면 내 사용자 폴더에 깔리고 바탕화면에 아이콘이 생겨요 |
| `SUMI-manual.md` | 사용설명서 |
| `rules_sample.json` | 규칙 견본 |

## 처음 설치할 때

1. `SUMI-Setup-버전.exe` 를 실행해요. 관리자 권한은 필요 없어요.
2. "Windows의 PC 보호" 파란 창이 뜨면 **[추가 정보] → [실행]** 을 눌러요. 서명 인증서가 없는 프로그램이라 뜨는 안내예요.
3. 바탕화면의 **SUMI** 로 켜요.

## 이미 쓰고 있다면

따로 받지 않아도 돼요. 프로그램을 켜면 새 버전을 알려 주고, 버튼 한 번으로 바뀌어요.
v0.5 이전(`SUMI.exe` 하나짜리)에서는 업데이트를 누르면 설치 마법사가 떠요. 설치가 끝나면 예전 `SUMI.exe` 자리는
새 SUMI 바로가기로 바뀌어요. 규칙·프로필·설정은 그대로 남아요.

## 할 수 있는 일

- 엑셀 파일·CSV 읽기, 엑셀에 열어 둔 문서에서 가져오기, 복사한 표 붙여넣기
- 컬럼마다 날짜·숫자·텍스트를 알아서 가려내고, 틀리면 직접 고치기
- "공정 도착 후 3일 넘게 대기" 같은 규칙을 여러 개 만들어 한 번에 골라내기
- 걸린 물량을 분류 기준으로 나누고 분류 표(교차표)로 보기
- 대시보드 위젯을 골라 배치하고, 분류 칸·컬럼 값·랏 단위로 날마다 추이 보기
- 결과를 엑셀 파일로 내보내기
- 로컬 LLM(Ollama 등)이나 사내 LLM 으로 말로 규칙 만들기·질문하기, 분류 기준 제안, 결과 요약·보고서, 달라진 점 설명, 규칙 점검

## 데이터는 어디로 가나요

- 읽은 표를 평문 파일로 남기지 않아요. 날마다 누적은 이 PC 의 설정 폴더에만 남고, 걸린 행의 값이 든 상세 누적은 윈도우 사용자 계정 암호화로 잠가 둬요(설정에서 끄거나 지울 수 있어요).
- 스스로 연결하는 바깥 주소는 새 버전 확인용 github.com 하나예요. 이때 보내는 데이터는 없어요.
- LLM 을 쓸 때만 표의 일부(컬럼 이름, 예시 값, 결과 행이나 요약)가 설정에 적은 주소로 가요.

## 필요한 환경

- Windows 10 이상 (64비트)
- 보호(DRM)가 걸린 엑셀 파일을 읽으려면 엑셀이 설치되어 있어야 해요
